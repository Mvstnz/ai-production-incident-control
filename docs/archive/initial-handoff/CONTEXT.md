# Fachliches Glossar

| Begriff | Definition |
|---|---|
| Incident | Ein zusammenhängender betrieblicher Störfall. Er kann mehrere Meldungen und Revisionen besitzen. |
| Source Event | Eine konkrete eingegangene Meldung aus einem bestimmten Quellsystem. Eine erneute Zustellung derselben Meldung ist kein neuer Geschäftsvorfall. |
| Incident Revision | Ein neuer fachlicher Stand eines bestehenden Störfalls, beispielsweise ein geänderter bestätigter Liefertermin. |
| Confirmed Supply | Eine verbindlich bestätigte Liefermenge zu einem festgelegten Termin. |
| Proposed Supply | Eine lediglich angebotene oder in Aussicht gestellte Liefermenge. Sie ist noch keine verlässliche Versorgung. |
| Partial Delivery | Ein Teil einer bestehenden Gesamtliefermenge. Er erhöht diese Gesamtmenge nicht. |
| Nettable Inventory | Bestand, der nach Berücksichtigung von Sperren und festen Zuordnungen für den betrachteten Bedarf nutzbar ist. |
| Production Requirement | Bedarf eines Produktionsauftrags an einem Material, einer Menge, einem Standort und einem Termin. |
| Referenced Production Order | Produktionsauftrag, der das betreffende Material oder Betriebsmittel verwendet. Das allein bedeutet noch keine Verspätung. |
| Under-supplied Production Order | Produktionsauftrag, dessen erforderliche Menge zum benötigten Zeitpunkt nicht vollständig gedeckt ist. |
| At-risk Sales Order Item | Offene Vertriebsposition, für die im betrachteten Szenario eine Überschreitung des zugesagten Liefertermins prognostiziert wird. |
| At-risk Order Value | Netto-Auftragswert der nach dem Modell gefährdeten offenen Mengen, ohne doppelte Zählung derselben Position. Kein erwarteter finanzieller Verlust. |
| Risk Score | Versionierter Priorisierungsindex von 0 bis 100, keine statistische Eintrittswahrscheinlichkeit. |
| Severity | Prioritätsklasse LOW, MEDIUM, HIGH oder CRITICAL. Sie kann durch eine ausdrücklich ausgewiesene Sicherheitsregel über dem Score-Ergebnis liegen. |
| Action Plan | Konkrete vorgeschlagene Maßnahmen zu einem bestimmten Stand des Incidents. |
| Approval | Entscheidung einer berechtigten Person über einen konkreten Inhalt und eine konkrete Planversion. |
| Mitigation | Gegenmaßnahme, die Folgen reduzieren soll. Ein Vorschlag ist noch keine wirksame Gegenmaßnahme. |
| Delivery Unknown | Der Ausgang einer externen Übertragung ist unklar; weder erfolgreiche Zustellung noch sicherer Fehlschlag ist belegt. |
| Resolution | Fachlich bestätigte Beseitigung oder akzeptierte Behandlung des Störfalls. Nicht gleichbedeutend mit dem Versand einer Warnung. |
| Demo Time | Explizit gesetzter fachlicher Zeitpunkt einer synthetischen Vorführung. Er ist von der tatsächlichen Ausführungszeit zu unterscheiden. |
| ERP Snapshot | Ein zusammenhängender, unveränderlicher Stand der für eine Berechnung verwendeten ERP-Fakten. |
